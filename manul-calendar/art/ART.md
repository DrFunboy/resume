# Арт: список картинок и правила

Все картинки в приложении — один и тот же манул в одном стиле. Главная сложность — единообразие, поэтому начните с эталонного листа персонажа.

## Технические правила

- Формат: WebP с прозрачным фоном. Размер 512–768 px по большей стороне (картинки сплэша — 2048 px и больше).
- Имена: латиница, нижний регистр, цифры, `_` (требование Android). Кладутся в `app/src/main/res/drawable-nodpi/`.
- Без текста и цифр на картинке: число дня рисует интерфейс.
- Генерировать на однотонном фоне и вырезать (например, `rembg`), если генератор не умеет прозрачность.
- Исходники из генераторов хранить в `art/raw/` (в git не попадают).
- Сверить условия коммерческого использования выбранного генератора, даже для личного приложения.

## Порядок работы

1. Эталонный манул: анфас, три четверти, профиль; зафиксировать стиль (плоская графика / акварель / 3D).
2. Остальные картинки — по эталону через image-to-image / «редактирование с референсом» (Gemini image, GPT image, Midjourney reference, FLUX Kontext и др.; возможности меняются, смотрите актуальные).
3. Каждый новый манул проверять рядом с эталоном: форма морды, пропорции, цвет шерсти, полоски на лбу.

### Праздники (`manul_holiday_<id>`)

`new_year` (1 янв), `christmas` (7 янв), `defender` (23 фев), `womens_day` (8 мар), `maslenitsa` (подвижный), `easter` (подвижный), `labor_day` (1 мая), `victory_day` (9 мая), `russia_day` (12 июн), `unity_day` (4 ноя).

Это стартовый набор; добавляйте и вычёркивайте. Праздник без своей картинки получает обычного манула дня.

### Иконки событий (`manul_icon_<категория>`)

Предложение, вычеркните лишнее и добавьте своё до шага 11 в `ROADMAP.md`:

| Категория | Ключевые слова (основы) |
|---|---|
| `cinema` | кино, фильм, сеанс |
| `doctor` | врач, доктор, поликлин, стоматолог, анализы |
| `restaurant` | ресторан, кафе, обед, ужин |
| `sport` | спорт, тренировк, зал, бассейн, бег |
| `travel` | поездк, отпуск, перелёт, самолёт, поезд, путешеств |
| `work` | работ, встреч, созвон, совещани |
| `shopping` | покупк, магазин, подарок |
| `study` | учёб, экзамен, лекци, курс |
| `beauty` | парикмахер, маникюр, массаж |
| `car` | авто, сто, шиномонтаж, ремонт машины |
| `party` | вечеринк, концерт, театр |

Размер иконок меньше, чем у картинок дня (они показываются в списке): достаточно 256 px.
