# Манул-календарь

Android-календарь для личного пользования (не для публикации в магазинах). У каждого дня в UI своя картинка манула.
Язык интерфейса — русский. Пользователь — программист, но не знает Kotlin/Java: объясняй неочевидные места Kotlin/Android коротко.

План и статус — в `ROADMAP.md`. Список картинок и правила арта — в `art/ART.md`.

## Что делает приложение

- События со временем и события на весь день; у события есть описание, место и ссылка (необязательные).
- Дни рождения (отдельный тип: дата без обязательного года, возраст если год задан).
- Повторы: каждую неделю / месяц / год.
- Напоминания о событиях и днях рождения.
- Три представления: **месяц**, **неделя**, **расписание** (список по дням, сверху вниз).
- Картинка манула у каждого дня в месяце и неделе (выбор — см. «Картинка дня»).
- Иконки манулов для событий по ключевым словам в названии (кино, врач, ресторан и т.п.).
- Сезонные манулы (зима / весна / лето / осень).
- Праздники России (+ тематические манулы), сплэш-анимация «зевок».

Не делаем: виджеты, задачи, синхронизацию с Google/CalDAV, импорт контактов, шаринг открыток, бэкап. Не добавляй без запроса.

## Стек

Kotlin, Jetpack Compose + Material 3, Room (+ KSP), DataStore, `java.time`, AlarmManager. minSdk 26, targetSdk 36, compileSdk 37 (его требуют версии зависимостей).
Без DI-фреймворка: зависимости собирает `AppContainer` в классе `Application`. Без бэкенда, всё офлайн.
Версии лежат в `gradle/libs.versions.toml`. Не меняй версии зависимостей и Gradle «заодно».
AGP 9.x со встроенным Kotlin: плагин `org.jetbrains.kotlin.android` не применять.
Динамические цвета Material You не используем: палитра задаётся манулами.

## Команды

Окружение (JDK 17 + Android SDK лежат в `~/.local/jdk-17` и `~/Android/Sdk`) подключается так:

```bash
source scripts/env.sh
./gradlew assembleDebug          # сборка APK: app/build/outputs/apk/debug/
./gradlew testDebugUnitTest      # JVM-тесты (domain/)
./gradlew installDebug           # установка на телефон по adb
```

Телефон: «Отладка по Wi-Fi» → `adb pair <ip:port>` → `adb connect <ip:port>`. Эмулятор в WSL2 не используем.
Каждый вызов Bash — новая оболочка, поэтому `source scripts/env.sh` нужен в той же команде.

## Архитектура (пакет `dev.manul.calendar`)

- `domain/` — чистый Kotlin, **без `android.*`**: модели, повторы, выбор картинки, праздники, ключевые слова → иконки. Покрывается JVM-тестами.
- `data/` — Room (entity, dao), репозитории, чтение JSON праздников из assets.
- `ui/` — Compose-экраны и ViewModel (состояние через `StateFlow`, события вверх, состояние вниз), `ui/theme/`.
- `reminders/` — планирование AlarmManager, BroadcastReceiver'ы, каналы уведомлений.

## Правила

- Логику повторов, выбора картинки, праздников и ключевых слов сначала покрывай тестами, потом пиши реализацию. UI проверяется глазами.
- Время: событие на весь день — `LocalDate`; событие со временем — `Instant` + `ZoneId`; день рождения — `MonthDay` + необязательный год. Только `java.time`, никаких `Date`/`Calendar`.
- Повторяющиеся события хранятся одной записью (правило в формате RRULE, RFC 5545) + таблица исключений; вхождения разворачиваются на лету только в видимое окно.
- Углы повторов, которые обязательно тестировать: 29 февраля, 31-е число, смена DST, правка «только это / это и следующие / все».
- Все строки интерфейса — в `res/values/strings.xml`, не в коде. Перевод на другие языки пока не планируется.
- Картинки — WebP в `res/drawable-nodpi/`, имена по схеме из `art/ART.md`. На картинках нет текста: цифры и подписи рисует UI.
- Пока арта нет, используй заглушки, но через ту же функцию выбора картинки, чтобы потом подменить только ресурсы.

## Напоминания (Android 12–16)

- Для личного пользования ограничения Google Play не важны: используем `USE_EXACT_ALARM` (Android 13+) и `SCHEDULE_EXACT_ALARM` с `maxSdkVersion="32"`.
- Уведомления Android 13+: runtime-разрешение `POST_NOTIFICATIONS`.
- Не планируй тысячи будильников: только ближайшие N, пересчёт при запуске, правке события, `BOOT_COMPLETED`, смене времени/часового пояса.
- WorkManager для точного времени не использовать (допускает задержку).
- Код напоминаний нужно проверять на реальном телефоне: LLM часто пишет по устаревшим примерам.

## Картинка дня (приоритет)

1. День рождения пользователя → манул в красном колпаке.
2. Праздник России с тематическим манулом.
3. День рождения другого человека → манул в зелёном колпаке.
4. Иначе → манул по числу месяца (`manul_day_01…31`).

Сезонный манул не заменяет картинку дня; он используется в шапке месяца/недели и для сезонного акцента (решение — в `ROADMAP.md`, «Открытые вопросы»).
Иконка события = ручной выбор пользователя, иначе по ключевым словам в названию, иначе без иконки.

## Подпись и установка

Релиз подписывается debug-ключом (`~/.android/debug.keystore`). Если ключ потерян, новую сборку нельзя поставить поверх старой без удаления приложения, а вместе с ним пропадут данные.
