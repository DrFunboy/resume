# Дорожная карта

Статус: `[x]` готово, `[ ]` не начато. Шаги идут вертикальными срезами: один шаг — одна рабочая фича — один коммит.

- [x] **0. Каркас.** Gradle (AGP 9.4, Kotlin 2.4), Compose + Material 3, тема, системный сплэш, иконка-заглушка, `CLAUDE.md`.
- [ ] **1. Арт-заглушки.** Положить в `res/drawable-nodpi/` временные картинки под имена из `art/ART.md`, чтобы код не ждал настоящий арт. Настоящий арт делается параллельно.
- [ ] **2. Домен и БД.** Модели `Event` (тип: со временем / на весь день / день рождения; название, описание, место, ссылка), правило повтора (RRULE) и исключения, напоминания. Room + репозиторий. **Сначала тесты** на раскрытие повторов.
- [ ] **3. Месяц.** Сетка (Pager с бесконечной прокруткой), первый день недели — понедельник, картинка в каждой ячейке (пока по числу месяца), точки/подписи событий.
- [ ] **4. Неделя.** Колонки дней с картинкой, список событий на день.
- [ ] **5. Расписание.** Бесконечный список по дням с липкими заголовками дат; в нём события, дни рождения и праздники. Переключение месяц / неделя / расписание.
- [ ] **6. Форма события.** Название, дата и время (или «весь день»), повтор, напоминания, **описание, место, ссылка** (ссылка кликабельна). Правка повторяющегося: «только это / это и следующие / все».
- [ ] **7. Напоминания.** Канал уведомлений, разрешения, AlarmManager, пересчёт после перезагрузки / смены времени. Кнопки «Отложить» и «Готово» — по желанию.
- [ ] **8. Дни рождения.** Профиль (дата рождения пользователя), события-ДР, возраст, 29 февраля, колпаки красный / зелёный.
- [ ] **9. Праздники России.** Фиксированные даты в коде, переносы выходных в JSON (`assets/`), подвижные (Масленица, Пасха) считаются алгоритмом. Тесты.
- [ ] **10. Картинка дня и сезоны.** Единая функция `imageFor(date)` с приоритетами из `CLAUDE.md`; сезонные манулы (см. «Открытые вопросы»).
- [ ] **11. Иконки событий по ключевым словам.** Таблица «основа слова → категория → картинка», ручной выбор иконки в форме события. Показываются в расписании и списке событий дня.
- [ ] **12. Сплэш «зевок».** Системный сплэш того же цвета → Compose-экран: пока данные грузятся — рот закрыт, затем рот открывается и картинка увеличивается к рту; тап по экрану пропускает; минимальная длительность ~1,5 с.
- [ ] **13. Настройки и полировка.** Тема (светлая / тёмная / системная), первый день недели, время напоминаний по умолчанию для событий на весь день и ДР, пропуск анимации.
- [ ] **14. Проверка на телефоне.** Перезагрузка, смена часового пояса, Doze, исключение из оптимизации батареи (Xiaomi / Samsung и т.п.).

## Открытые вопросы

- **Сезонные манулы.** Предложение: 4 картинки (или 12 — по месяцам) в шапке экранов месяца и недели плюс небольшой сезонный акцент цвета. Тогда 31 картинка дня остаётся одним набором. Вариант «31 × 4 сезона» (124 картинки) заметно дороже по арту. Решить до шага 10.
- **Какой манул побеждает в конфликте.** Сейчас: ДР пользователя → праздник → ДР другого → обычный. Если ДР друга должен перебивать праздник, поменять порядок в `CLAUDE.md` и в тестах шага 10.
- **Список категорий иконок.** Стартовый набор в `art/ART.md`, вычеркните лишнее и добавьте своё до шага 11.

## Риски

- Данные хранятся только на телефоне. При смене ключа подписи или удалении приложения они теряются. Если это станет проблемой, добавить экспорт/импорт JSON (не входит в план).
- Напоминания на телефонах Xiaomi / Huawei / Samsung могут не срабатывать из-за энергосбережения: настройка пользователем в системных настройках.
