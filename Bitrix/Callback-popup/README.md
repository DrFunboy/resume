# Форма обратного звонка в 1С-Bitrix

## Стек:
* Bitrix (модуль «Веб-формы»)
* компонент bitrix:form.result.new
* Vue 3
* Модуль sprint.migration https://marketplace.1c-bitrix.ru/solutions/sprint.migration/

## Задача:
Сделайте форму обратного звонка во всплывающем окне.

Окно должно само открываться через 20 секунд после того, как пользователь зашёл на страницу, в форме должна быть валидация полей.

Поля формы нельзя зашивать во Vue вручную. Их настраивают в админке Bitrix (веб-форма), а фронт только рисует то, что пришло из бэка.

Верстка на Bootstrap, важна адаптивность.

### Этапы работы:
1. Создание веб-формы. Обязательные поля: Имя, телефон, согласие на обработку данных. Необязательные: комментарий
2. Свой шаблон bitrix:form.result.new
3. Сборка JSON с полями
4. Vue - модальное окно - отправка
5. Миграция формы через модуль sprint.migration
